# ExpenseSnap

Offline-first time and expense capture for freelancers and microbusinesses.

- Log billable hours or project expenses.
- Group by client/project and estimate billable totals.
- Export CSV and JSON backup.
- Local browser storage; no account or paid API.

Limits: no invoicing, tax advice, payments, timer, accounting integration, cloud backup or team sync. Totals are estimates.

Open index.html in a modern browser.

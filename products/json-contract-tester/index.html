Supported rules and current limitations

Supported: type, required, properties, additionalProperties=false, items, enum, const, minimum, maximum, minLength, maxLength, pattern, minItems, and maxItems. Limits: one JSON value per non-empty line; object/array schema nodes only; no $ref/$defs, composition (allOf/anyOf/oneOf/not), format checks, boolean schemas, or additionalProperties schemas. Pattern uses this browser's JavaScript regular-expression engine. Unknown keywords are ignored. A PASS means only that the value matches the rules listed here, not that it is valid under the full JSON Schema specification. Use a full validator for production or security-critical contracts.

Prueba contratos JSON para API y agentes de IA

Falcon JSON Contract Tester es una herramienta gratuita que funciona en el navegador para comparar varios ejemplos JSON con un contrato JSON Schema y descargar un informe de pruebas.

Cómo usarla

  1. Pega o carga un JSON Schema.
  2. Añade varios ejemplos JSON representativos.
  3. Ejecuta las pruebas y revisa el resultado PASS/FAIL.
  4. Descarga el informe JSON para compartirlo con tu equipo.

Abrir el probador gratuito

Limitación: esta versión implementa solo un subconjunto documentado de JSON Schema. Un resultado PASS no garantiza compatibilidad completa, seguridad ni aptitud para producción. No pegues secretos, credenciales ni datos personales.

¿Qué feedback nos ayudaría?

Buscamos ejemplos reproducibles de respuestas de API o agentes que deberían fallar según un contrato. Si encuentras un caso límite, comparte una muestra sintética y la regla esperada en el repositorio del proyecto.

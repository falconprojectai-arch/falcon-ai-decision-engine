API・AIエージェント向け JSON 契約テスター

Falcon JSON Contract Tester は、複数の JSON サンプルを JSON Schema 契約と照合し、テストレポートをダウンロードできる無料のブラウザーツールです。

使い方

  1. JSON Schema を貼り付けるか読み込みます。
  2. 代表的な JSON サンプルを複数追加します。
  3. テストを実行し、PASS/FAIL の結果を確認します。
  4. JSON レポートをダウンロードしてチームと共有します。

無料テスターを開く

制限事項：現在のバージョンは、文書化された JSON Schema の一部のみを実装しています。PASS は完全な仕様準拠、安全性、本番利用への適合を保証しません。秘密情報、認証情報、個人データを貼り付けないでください。

フィードバック募集

契約上は失敗するはずなのに検出できない API／エージェント応答の再現可能な例を探しています。合成データと期待するルールを GitHub の課題ページで共有してください。

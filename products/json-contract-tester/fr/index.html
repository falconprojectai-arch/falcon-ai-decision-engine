Tester les contrats JSON d’API et d’agents IA

Falcon JSON Contract Tester est un outil gratuit dans le navigateur qui compare plusieurs exemples JSON à un contrat JSON Schema et permet de télécharger un rapport de test.

Mode d’emploi

  1. Collez ou chargez un JSON Schema.
  2. Ajoutez plusieurs exemples JSON représentatifs.
  3. Lancez les tests et examinez les résultats PASS/FAIL.
  4. Téléchargez le rapport JSON pour le partager avec votre équipe.

Ouvrir le testeur gratuit

Limite : cette version ne prend en charge qu’un sous-ensemble documenté de JSON Schema. PASS ne garantit ni la conformité complète, ni la sécurité, ni l’aptitude à la production. Ne collez aucun secret, identifiant ou donnée personnelle.

Retours recherchés

Nous cherchons des cas reproductibles où une réponse d’API ou d’agent devrait échouer selon le contrat. Partagez un exemple synthétique et la règle attendue dans le dépôt du projet.

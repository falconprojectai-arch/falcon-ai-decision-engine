## Full description
JSON Contract Tester helps developers compare several JSON outputs against one schema before shipping API responses or AI-agent results. Paste a schema and one JSON value per line, run the batch, inspect PASS/FAIL per sample, and download a machine-readable JSON report.

The tool runs in the browser without sign-up and is designed not to upload input data. It is a small utility, not a full JSON Schema implementation: supported keywords and limitations are documented on the page. It does not support $ref/$defs, composition keywords, format assertions, boolean schemas, or schema-valued additionalProperties. A PASS means only that the value matches the supported rules. Use a full validator for production or security-critical contracts.

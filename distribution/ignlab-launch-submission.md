## Full description
JSON Contract Tester is a free, browser-only utility for checking several JSON samples against one schema. It shows PASS/FAIL per sample and can export a machine-readable JSON report. The samples are processed locally in the browser; no sign-up is required and the tool is designed not to upload your JSON.

Important limitation: this is a lightweight validator for a documented subset of JSON Schema, not a complete implementation. Review the supported keywords and known gaps before relying on it. Do not use this MVP as the sole validator for production, security-sensitive, or compliance-critical data.

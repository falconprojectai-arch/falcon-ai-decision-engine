# Public agent skills

This directory contains installable Agent Skills in the open `SKILL.md` format.

## Install

```bash
npx skills add falconprojectai-arch/falcon-ai-decision-engine
```

Select **Lead Follow-up Strategist** from the repository's skills when prompted. Review the skill source before installation.

## Available skills

| Skill | Purpose | Source |
|---|---|---|
| Lead Follow-up Strategist | Consent-aware drafts and next-step plans for genuine inbound leads; draft-only, never sends messages or books customers. | [SKILL.md](lead-followup-strategist/SKILL.md) |

The skill is also listed on [Agensi](https://agensi.io/skills/lead-follow-up-strategist). The Agensi listing may have a separate review status; a GitHub source publication does not imply marketplace approval or usage.

## Scope and safety

This skill is an instruction package, not a messaging integration. It does not connect to a CRM, send messages, make calls, book appointments, or process payments. Do not include unnecessary personal or sensitive data in prompts.

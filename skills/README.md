# Public Agent Skills

[![skills.sh](https://skills.sh/b/falconprojectai-arch/falcon-ai-decision-engine)](https://skills.sh/falconprojectai-arch/falcon-ai-decision-engine) · [GitHub repository](https://github.com/falconprojectai-arch/falcon-ai-decision-engine)

This repository publishes reusable Agent Skills in the open `SKILL.md` format. They are procedural instructions, not standalone integrations. Review each package before installation.

## Install

```bash
npx skills add falconprojectai-arch/falcon-ai-decision-engine
```

Select the relevant skill from the repository. The source packages are organized under `skills/<skill-name>/SKILL.md`.

## Discovery and indexing

- **skills.sh** does not provide a manual submission form or crawl every GitHub repository. Its index is driven by genuine `npx skills add <owner>/<repo>` install telemetry. This repository is installable now; its skills will appear only after real users install it and the service indexes the telemetry. We do not create artificial self-installs or inflate install counts.
- **SkillsMP** describes automatic indexing of public GitHub repositories containing valid `SKILL.md` files. The repository was not yet returned by public search at the last check; indexing is not claimed until verified.

## Marketplace status

All nine free Agensi listings were independently rechecked on 2026-11-12 and showed `live` with `approved` security status. The creator dashboard reported zero uses, ratings and reviews at that check. A public source package or directory listing does not imply customer usage or revenue.

## Scope and safety

These skills do not create integrations or authorize external actions by themselves. Unless a skill explicitly says otherwise, they provide instructions, analysis, drafts and local workflows only. They do not send messages, book appointments, change records, charge customers, execute trades, or process payments.
